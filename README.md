# mixin 安装包 · Installers

这里只放 **mixin** 的安装包。mixin 是一个 macOS 输入法：拼音、英文、代码、公式放在一起打，不用切换输入法。介绍和下载：**https://usemixin.com**

This repository only hosts installers for **mixin**, a macOS input method for typing Chinese pinyin, English, code and math together. See **https://usemixin.com**.

- 系统要求 / Requirements: macOS 14 or later, Apple silicon.
- 安装：打开磁盘映像，把 mixin 拖到「应用程序」，然后打开它，按窗口里的步骤装好输入法。卸载也在 mixin 里。
  Install: open the disk image, drag mixin to Applications, open it and follow its steps. Uninstall from the app too.
- 内测版还没有经过 Apple 公证：第一次打开如果被拦下，到「系统设置 → 隐私与安全性」点「仍要打开」。
  The beta is not notarized yet: if macOS blocks the first launch, allow it under System Settings → Privacy & Security → Open Anyway.
- 第三方许可和词库的构建源码在 mixin 里（「许可与来源」）。Third-party licences and the dictionary's build sources are inside the app (「许可与来源」).
- 问题和建议 / Contact: support@usemixin.com
