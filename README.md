# mixin 安装包 · Installers

这里只放 **mixin** 的安装包。mixin 是一个 macOS 输入法：拼音、英文、代码、公式放在一起打，不用切换输入法。介绍和下载：**https://usemixin.com**

This repository only hosts installers for **mixin**, a macOS input method for typing Chinese pinyin, English, code and math together. See **https://usemixin.com**.

- 系统要求 / Requirements: macOS 14 or later, Apple silicon.
- 内测版没有经过 Apple 公证。安装时双击磁盘映像里的「安装 mixin」，第一次会被 macOS 拦下，到「系统设置 → 隐私与安全性」点「仍要打开」。详细步骤见磁盘映像里的「使用说明」。
  The beta is not notarized yet: run 「安装 mixin」 from the disk image and allow it once under System Settings → Privacy & Security → Open Anyway.
- 第三方许可和词库的构建源码在磁盘映像的「许可与来源」文件夹里。Third-party licences and the dictionary's build sources are in the disk image's 「许可与来源」 folder.
- 问题和建议 / Contact: support@usemixin.com
